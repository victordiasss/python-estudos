# Exercícios de Python

Este repositório contém uma coleção de exercícios básicos de Python, organizados por número e tema.

## Estrutura

Os arquivos foram nomeados mantendo a numeração original e adicionando um identificador descritivo relacionado ao conteúdo do exercício.

## Objetivo

Este projeto serve como registro dos exercícios resolvidos em Python, com foco em prática de lógica, entrada e saída de dados, operações matemáticas e estruturas básicas da linguagem.
